# LRMC: Learnable-Radius Margin-Contrastive zero-day malware detection

Research codebase for "Artificial Intelligence Based Zero-Day Malware
Detection Using Contrastive Learning". See:

- `docs/ARCHITECTURE.md` -- module layout, mapped to the two pipeline diagrams.
- `docs/LRMC.md` -- the loss math, LaTeX-ready.
- `docs/DECISIONS.md` -- design choices made under ambiguity, with rationale.
- `HANDOFF.md` -- the runbook for the college GPU workstation.
- `Makefile` -- `make install`, `make test`, `make rehearsal`.

Quick start: `python scripts/setup_env.py`, then see `HANDOFF.md`.
